Main rule
---------
Add the new thing to the correct definition list first. Then run datagen. Avoid manually creating
generated json files unless the system does not support that thing yet.

Datagen command
---------------
Run:

gradlew runData

Generated resources go to:

src/generated/resources

The build already includes this folder as a resource folder.

Checklist after adding anything dynamic
---------------------------------------
1. Add the new definition, enum value, or list entry.
2. Add textures or material set assets if the generated model needs them.
3. Run gradlew runData.
4. Check src/generated/resources for the expected json files.
5. Start the client and check the creative tabs.
6. Check names, colors/tints, blockstates, item models, and tooltips.
7. For multiblocks, place the controller and verify preview/formation.
8. For recipes, verify recipe matching and required ports.
