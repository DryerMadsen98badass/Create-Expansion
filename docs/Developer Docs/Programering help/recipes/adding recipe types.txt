Create Expansion - Adding CE Recipe Types
=========================================

Put one recipe type definition per file in `recipe/recipetypes`, then include it in
`CERecipeTypes.ALL`.

```java
import net.mads.createexpansion.recipe.RecipeTypeDefinition.Option;

public static final RecipeTypeDefinition HAMMERING = RecipeTypeDefinition.recipeType()
        .recipeTypeDefinition(Option.id("hammering"))
        .recipeTypeDefinition(Option.displayName("Hammering"))
        .recipeTypeDefinition(Option.maxIO(1, 1, 0, 0))
        .recipeTypeDefinition(Option.energyInput())
        .recipeTypeDefinition(Option.noKinetic())
        .recipeTypeDefinition(Option.progressBar(ProgressBar.HAMMER))
        .build();
```

The recipe type defines maximum item/fluid IO, permitted energy and kinetic directions, supported
logic, and the default JEI/machine progress bar. Ctrl+Click an `Option` method for its JavaDoc.

CE multiblocks use the recipe type's requirements to resolve needed item, fluid, kinetic, and
energy abilities. Create recipe types do not use `RecipeTypeDefinition` and remain unchanged.
